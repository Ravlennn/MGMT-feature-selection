# Оценка отбора признаков на UPenn-GBM

**Статус:** итоговый отчёт по сокращённому протоколу
`--skip-ga --random-repeats 20`, составленный по исходным CSV, OOF-прогнозам

## Цель и данные

Сравнить Le/F-score и Calabrese-inspired MI → RF-RFE на одной когорте
UPenn-GBM с моделью без отбора признаков и случайными наборами такого же
размера. Клинические метки взяты из
`data/raw/upenn/clinical/UPENN-GBM_clinical_info_v2.1.csv`: из 671 записи
348 имели `Not Available`, 32 — `Indeterminate`; 291 пациент имел
однозначный MGMT-статус. Пересечение с 12 таблицами радиомики CaPTk
структурной МРТ (FLAIR, T1GD, T1, T2 × ED, ET, NC; 144 признака на блок)
оставило 256 пациентов: 148 unmethylated и 108 methylated. Потери при
последовательном merge: 291 → 262 на FLAIR_ED (−29) → 258 на FLAIR_ET
(−4) → 256 на FLAIR_NC (−2); остальные девять блоков пациентов не удалили.
DTI и DSC не использованы.

Вход в настоящую оценку — **до когортной очистки**:
`data/processed/upenn/upenn_structural_raw.csv`, 256 × 1728 признаков
(плюс `SubjectID`, `MGMT`, `target`). Его SHA-256
`cfbe209c168971b9324420cb265194a947a15089b59c57bcb9e803f23fac3647`
совпадает с `run_metadata.json`. В ознакомительном протоколе очистка всей
матрицы удалила 84 константы и 164 точных дубликата, затем заполнила
четыре пропуска в четырёх оставшихся признаках, получив 1480 признаков.
В настоящем прогоне очистка обучалась заново внутри каждого фолда;
число сохранённых признаков на внешних обучающих частях: 1478–1480,
в среднем 1479.2.

Таблица параметров предоставлена как
`data/raw/upenn/parameters/UPENN-GBM_CaPTk_fe_params.csv`;
это признаки CaPTk, версия PyRadiomics к этой выгрузке неприменима.
Фактическую версию CaPTk архив не устанавливает.

## Протокол

- Общие пять стратифицированных внешних фолдов для всех методов. На каждом
  внешнем обучающем фолде заново удаляются константы и точные дубликаты,
  вычисляются медианы для пропусков; проверочные пациенты не используются.
- Внутри внешнего обучения пятифолдовая CV выбирает `C` Logistic
  Regression с L2-регуляризацией из шести значений: 0.001, 0.01, 0.1,
  1, 10, 100. Препроцессинг, отбор и масштабирование включены в pipeline.
- Le: top-9 по F-score. Calabrese-inspired: Mutual Information до 1024
  кандидатов, затем RF-RFE до 32 признаков в профиле `practical`.
  `all_features` использует все признаки после очистки обучающего фолда.
- `random_9` и `random_32` повторены по 20 раз на тех же внешних фолдах.
  Для парных сравнений до просмотра результатов зафиксирован повтор 0;
  распределение всех 20 повторов показано отдельно.
- На каждом внешнем проверочном фолде получается вероятность MGMT=1;
  объединённые out-of-fold прогнозы используются для AUROC. 95% интервалы
  построены 2000 стратифицированными перевыборками пациентов по готовым
  прогнозам. Для пяти заданных пар применены парный DeLong и поправка Holm.

Случайное состояние внешних фолдов — 42. Профиль селектора `practical`:
MI оставляет 1024 кандидата, RF-RFE в трёх внутренних разбиениях с лесом
по 100 деревьев выбирает 32 признака. Ранги RF-RFE и MI объединяются
только внутри обучающей части. Использованы scikit-learn 1.9.1 и pandas
3.0.6; SHA-256 реализации из метаданных:
`86721b02c61edbd4aa9232865ded8e5d3776f53e4631660e5450c32f10cb18dc`.
В метаданных по умолчанию записаны пять сидов GA и общее имя протокола,
но строк GA в фактических CSV этого запуска **нет**.

## Результаты

| Метод | Признаков | Средний AUROC внешних фолдов ± SD | AUROC всех OOF | 95% bootstrap CI для повтора 0 |
|---|---:|---:|---:|---:|
| Le/F-score | 9 | 0.408 ± 0.070 | 0.423 | 0.355–0.490 |
| Calabrese-inspired MI → RF-RFE | 32 | 0.421 ± 0.101 | 0.462 | 0.391–0.531 |
| Все признаки, L2 Logistic Regression | в среднем 1479.2 | 0.432 ± 0.032 | 0.434 | 0.367–0.506 |
| Случайные 9, фиксированный повтор 0 | 9 | 0.457 ± 0.093 | 0.465 | 0.394–0.538 |
| Случайные 32, фиксированный повтор 0 | 32 | 0.478 ± 0.041 | 0.473 | 0.405–0.544 |

На 20 запусках `random_9` средний OOF AUROC равен **0.459 ± 0.036**
(минимум 0.404, максимум 0.534); для `random_32` — **0.456 ± 0.029**
(минимум 0.411, максимум 0.517). Здесь SD характеризует разброс между
разными случайными наборами, а не неопределённость оценки для новых пациентов.

| Сравнение: первый минус второй | Δ AUROC | 95% парный bootstrap CI | DeLong p после Holm |
|---|---:|---:|---:|
| Le − random 9 | −0.042 | −0.128–0.046 | 1.000 |
| Calabrese − random 32 | −0.010 | −0.095–0.076 | 1.000 |
| Le − все признаки | −0.012 | −0.095–0.069 | 1.000 |
| Calabrese − все признаки | +0.028 | −0.055–0.112 | 1.000 |
| Le − Calabrese | −0.040 | −0.127–0.048 | 1.000 |

Во всех пяти сравнениях 95% интервалы разницы включают ноль. На этой
когорте и при выбранном протоколе нет убедительного преимущества Le или
Calabrese перед моделью без отбора либо случайным набором того же размера.
Числа AUROC для отдельных методов близки к 0.5 или ниже: полезный
обобщающийся сигнал MGMT в этом эксперименте не продемонстрирован.

## Какие признаки выбирались

Ниже приведена **описательная** сводка наборов повтора 0 из
`selected_features_by_fold.csv`. Jaccard рассчитывался для всех 10 пар
пяти внешних фолдов отдельно по каждому селектору; фолды имеют частично
перекрывающиеся обучающие множества. Это не оценка бутстрэп-стабильности
из TODO 2.

| Метод | Выбрано на фолд | Разных признаков в объединении | Общих всем 5 | Средний Jaccard между фолдами | Доля FLAIR среди назначений |
|---|---:|---:|---:|---:|---:|
| Le/F-score | 9 | 40 | 0 | 0.031 | 18/45 = 40% |
| Calabrese-inspired MI → RF-RFE | 32 | 128 | 0 | 0.064 | 40/160 = 25% |

У Le пять признаков появились дважды, остальные 35 — один раз; у
Calabrese шесть признаков появились в трёх фолдах, 20 — в двух и 102 —
в одном. Например, `FLAIR_ET_Morphologic_Eccentricity` встречался у Le
в двух фолдах, а у Calabrese — в трёх. Среди 160 назначений Calabrese
по модальностям: T2 — 50, FLAIR — 40, T1GD — 36, T1 — 34. Для Le:
FLAIR — 18, T2 — 13, T1GD — 9, T1 — 5. Это подсчёт назначений с
повторами, а не доли независимых маркеров или свидетельство важности
модальности для MGMT.

Le и Calabrese на одинаковых внешних фолдах выбрали соответственно
3, 0, 2, 0 и 0 общих признаков из наборов по 9 и 32. Средний Jaccard
между двумя методами на совпадающем фолде — 0.026. Пересечение может
быть чувствительно к коррелированным, близким по смыслу признакам:
разные имена не обязательно означают разную информацию.

## Интерпретация и ограничения

Прежние ознакомительные AUROC около 0.60 получены по другой схеме с
отбором на полной таблице до downstream CV. Сопоставлять их с внешними
OOF AUROC как оценки одного протокола нельзя. Различия могут зависеть и от
параметров методов, поэтому снижение метрик нельзя приписать только утечке.

Bootstrap переотбирает пациентов с уже готовыми OOF-прогнозами, не
повторяя обучение и feature selection. DeLong для OOF-прогнозов,
полученных разными обученными моделями, рассматривается как приближённая
исследовательская статистика. Независимой внешней когорты здесь нет.
SD внешних фолдов относится к одному разбиению на пять частей, а не к
пяти независимым повторам всей процедуры. Все 43 OOF AUROC пересчитаны
из 11008 строк прогнозов и совпали с `summary.csv`; каждый запуск даёт
один прогноз каждому из 256 пациентов, повторов случайных методов по 20.

GA-RF/Do и соответствующий случайный K-бейзлайн исключены по вычислительной
стоимости. Низкий AUROC упрощённого `--quick` запуска не является
доказательством низкого качества полного GA. Поэтому исходное требование
TODO 1 о пяти сидах GA **не выполнено**, а сравнение всех трёх методов
из статей пока невозможно. Бутстрэп-стабильность выбранных наборов
признаков из TODO 2 также ещё не оценивалась.
